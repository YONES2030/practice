# Bug Report

## Bug ID
BUG-001

## Title
Quick navigation—Legal Information-->Responsible Gambling :the back bottom of this page is not working.

## Environment
- Platform: melbet
- Browser: chrome
- OS: mobile phone (android)
- Website: melbet.com
- Build/Version: (android 14)

## Preconditions
- User is not registered/logged in.

## Steps to Reproduce
1. Open Website: open the main website link.
2. Scroll down to the footer section.
3. Go to quick navigation—Legal Information.
4. Open a Responsible Gambling link.
5. Wait until the page loads completely.
6. click Back navigation bottom and Confirm that you can return to the previous page.
   
## Actual Result
the back bottom of the Responsible Gambling page is not working.

## Expected Result
the back bottom of the Responsible Gambling page returns you to the previous page.

## Severity
high

## Priority
Critical

 ## Bug ID
BUG-002

## Title
missing (Deposit) button on registration success mode.

## Environment
- Platform: melbet
- Browser: chrome
- OS: desktop (windows) 
- Website: melbet.org
- Build/Version: windows 11

## Preconditions
- User is not registered/logged in.
- User has access to a social network account.

## Steps to Reproduce
1. Open the Melbet website on desktop.
2. Click "Sign Up".
3. Select a social network registration option.
4. Complete the registration process using the social network account.
5. Observe the success modal displayed after successful registration.

## Actual Result
The registration success modal is displayed, but the "Deposit" button is missing.

## Expected Result
The registration success modal should contain a "Deposit" button, allowing the newly registered user to proceed directly to the deposit page.

## Severity
Medium

## Priority
High
