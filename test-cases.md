# Test Cases

## TC-001 — Successful Login

**Preconditions:**
- User has a registered account.
- User is on the Login page.

**Steps:**
1. Enter a valid email address.
2. Enter a valid password.
3. Click the "Login" button.

**Expected Result:**
- User is successfully logged in.
- User is redirected to the main page.

---

## TC-002 — Login with Invalid Password

**Preconditions:**
- User has a registered account.
- User is on the Login page.

**Steps:**
1. Enter a valid email address.
2. Enter an incorrect password.
3. Click the "Login" button.

**Expected Result:**
- User is not logged in.
- An appropriate error message is displayed.

---

## TC-003 — successful register account with phone
**Preconditions:**
- User has to be logged out.
- User is on the registration page-> by phone.

**Steps:**
1. Choose Welcome Bonus.
2. Enter phone number and tap "Send via SMS".
3. Verify using the code sent to your phone.
4. Select account currency.
5. Tap "Register".

**Expected Result:**
- User is successfully registered an account.
- User is redirected to the deposit page.
